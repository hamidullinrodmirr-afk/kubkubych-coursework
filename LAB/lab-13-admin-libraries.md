# Лабораторная 13 Дополнительные библиотеки для админки

Подключены django-simple-history для Product и Order, а также django-import-export для Category и Product. История нужна для контроля изменения карточек и заказов. Экспорт используется для передачи товарного каталога и категорий без доступа к базе данных.

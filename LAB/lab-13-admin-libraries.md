# Отчёт по лабораторной работе 13
## История изменений и импорт/экспорт

### Цель работы
Подключить библиотеки для аудита изменений и обмена данными каталога.

### История моделей
django-simple-history подключена в INSTALLED_APPS, а HistoryRequestMiddleware — в middleware. Product и Order содержат HistoricalRecords:
~~~python
history = HistoricalRecords()
~~~

Созданные миграции добавляют исторические модели. Они позволяют хранить предыдущие состояния товара и заказа. Выбор этих объектов обусловлен значимостью цены, остатка и состояния заказа для разбора изменений.

Вместе с тем ProductAdmin наследует ImportExportModelAdmin, OrderAdmin — ModelAdmin; SimpleHistoryAdmin не подключён. Исторические записи и стандартная кнопка истории Django Admin — разные механизмы. Специализированный интерфейс библиотеки не заявляется как настроенный.

### Импорт и экспорт
CategoryAdmin и ProductAdmin наследуют ImportExportModelAdmin. Для Product задан ресурс:
~~~python
class ProductResource(resources.ModelResource):
    class Meta:
        model = Product
        fields = (
            'id', 'article', 'name', 'category__name',
            'price', 'stock', 'is_active'
        )
~~~

Экспорт ограничен полями каталога. Для Category применяется ресурс по умолчанию. Обоснование выбора: категории являются справочником, товары — основными данными магазина, которые удобно передавать табличным файлом.

Экспорт связан с названием серии, но это не гарантирует симметричный импорт по нему: отдельный ForeignKeyWidget не настроен. Также наличие кнопок библиотеки не доказывает доступность XLSX без соответствующих зависимостей tablib.

### Миграции и результат
В предоставленном showmigrations исторические миграции Product и Order отмечены [X]. Это подтверждает применение структуры исторических таблиц. Действия импорта, выгрузка Excel и создание записи истории конкретным тестовым изменением не были зафиксированы.

### Вывод
Подключены исторические модели и административное расширение импорта/экспорта для двух объектов. Текущая реализация содержит инфраструктуру библиотек, но специализированный интерфейс истории и сценарий Excel требуют отдельного завершения.

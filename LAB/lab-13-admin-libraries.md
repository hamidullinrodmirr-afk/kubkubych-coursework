# Лабораторная работа 13 Дополнительные библиотеки для админки

## Цель

Подключить расширения Django Admin для аудита изменений и обмена данными.

## Подключённые библиотеки

| Библиотека | Объекты | Обоснование |
| --- | --- | --- |
| `django-simple-history` | `Product`, `Order` | позволяет увидеть, кто и когда изменил товар или заказ; это важно для разбора ошибок в каталоге и обработке заказа |
| `django-import-export` | `Category`, `Product` | позволяет выгружать и загружать справочник серий и каталог без ручного редактирования базы данных |

Зависимости перечислены в `requirements.txt`. Для `Product` используется `ProductResource`, ограничивающий экспортируемые поля; `Category` и `Product` зарегистрированы через `ImportExportModelAdmin`.

## Сценарий демонстрации

1. Изменить тестовый набор или заказ в админке и открыть его историю.
2. Открыть список категорий, выбрать экспорт и сохранить файл результата.
3. Повторить экспорт для набора; показать перечень полей ресурса.
4. Не импортировать данные в основную базу без резервной копии и проверки файла.

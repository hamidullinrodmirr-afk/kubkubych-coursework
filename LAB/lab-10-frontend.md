# Отчёт по лабораторной работе 10
## Доступность интерфейса и печатное представление

### Цель работы
Рассмотреть адаптацию интерфейса магазина для разных экранов, клавиатурной навигации и печати.

### Устройство интерфейса
Общий шаблон base.html содержит язык документа, навигацию, стили и сценарии. Карточки товаров создаются productCard из static/js/app.js. Изображения получают alt с названием набора; кнопка избранного использует aria-label. Поле поиска главной связано с подписью.

CSS содержит адаптивные правила для ширин 1024, 860, 768 и 480 пикселей. На узких экранах изменяются сетки каталога, корзины, форм и подвала. Мобильное меню переключается JavaScript.

### Движение и фокус
Стили предусматривают видимый фокус. JavaScript проверяет prefers-reduced-motion и при включённом предпочтении не запускает анимацию появления и счётчиков. Это уменьшает избыточное движение интерфейса.

### Печатные стили
~~~css
@media print {
    @page { margin: 18mm; }
    body {
        color: #000;
        background: #fff;
        font-family: Arial, sans-serif;
    }
    .header, .footer, .btn, .home-search,
    .product-detail__actions, .review-form, .alert {
        display: none !important;
    }
    .product-detail, .order-detail__grid { display: block; }
}
~~~

Фрагмент сокращён до основных правил. Полный блок также скрывает отдельные действия корзины, ограничивает размер изображения и уменьшает разрывы информационных блоков между страницами.

Печатается уже сформированный браузером документ; наличие данных зависит от успешной загрузки API до открытия печати.

### Результат и вывод
В исходниках реализованы адаптивные сетки, базовые доступные подписи и отдельное печатное оформление. Открытие главной страницы в браузере подтверждено ранее. Полный аудит доступности и визуальная проверка печати не проводились; соответствие конкретным стандартам доступности не заявляется.

# Лабораторная 2 Административная часть Django

Административная часть доступна по `/admin/`. Для товаров добавлены фильтры, поиск, даты, readonly-поля, выбор связанной серии по `raw_id_fields`, экспорт через django-import-export и генерация PDF-спецификаций. Заказы используют inline-позиции, отзывы — массовые действия модерации.

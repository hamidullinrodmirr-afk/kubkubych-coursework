# Отчёт по лабораторной работе 2
## Административная часть Django

### Цель работы
Настроить административный интерфейс для управления объектами интернет-магазина и связанными данными.

### Реализация
Основной адрес административной части — /admin/. Объекты зарегистрированы в admin.py своих приложений. Модели определяют человекочитаемый __str__; русские имена заданы у основных моделей, но не у всех служебных моделей и полей.

| Объект | Настройки интерфейса |
| --- | --- |
| Category | Список, фильтр активности, поиск, заполнение slug, импорт/экспорт |
| Product | Список, фильтры серии/активности/скидки, поиск названия/артикула, календарная иерархия, readonly-поля, выбор серии по ID, PDF-действие |
| Order | Список заказов, фильтры, поиск, readonly-поля и inline-позиции |
| Favorite | Пользователь, товар, дата и поиск по связанным данным |
| Review | Список и действия одобрения/отклонения |
| User | Email, имя, роль, активность и стандартные права Django |

### Основной код
~~~python
class ProductAdmin(ImportExportModelAdmin):
    list_display = (
        'name', 'article', 'category', 'price',
        'discount_percent', 'final_price', 'stock', 'is_active'
    )
    list_filter = ('category', 'is_active', 'discount_percent')
    search_fields = ('name', 'article')
    date_hierarchy = 'created_at'
    list_display_links = ('name',)
    raw_id_fields = ('category',)
    readonly_fields = ('created_at', 'updated_at')
    actions = ('export_specs_pdf',)
~~~

Метод final_price оформлен @admin.display(description='Цена со скидкой'). Он выводит вычисленное свойство модели как колонку списка. Декоратор задаёт заголовок колонки; это современная форма настройки описания метода.

OrderItemInline встроен в OrderAdmin. Позиции видны в карточке заказа, поля снимка покупки доступны только для чтения, удаление inline отключено. Такой подход сохраняет состав оформленного заказа.

UserAdmin наследует стандартный BaseUserAdmin. Поля groups и user_permissions присутствуют в интерфейсе управления пользователем; настройка наследуемых возможностей должна оцениваться отдельно от собственного M:N через Favorite.

### Назначение настроек
Поиск помогает найти товар по артикулу. list_filter ограничивает выборку по серии и активности. raw_id_fields позволяет выбрать связанную серию через её идентификатор. readonly_fields препятствуют ручному изменению временных меток в форме администратора. date_hierarchy добавляет навигацию по датам.

### Результат и вывод
Административная часть объединяет управление каталогом и заказами, просмотр связанных позиций, экспорт и массовые действия. Проверка manage.py check завершилась сообщением System check identified no issues. Полный ручной проход по всем административным страницам в этой работе не зафиксирован.

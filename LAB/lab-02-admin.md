# Лабораторная работа 2 Административная часть Django

## Цель

Настроить Django Admin для управления данными интернет-магазина и продемонстрировать средства работы со связанными объектами.

## Реализованные возможности

| Объект | Подтверждённая настройка |
| --- | --- |
| `Category` | `ImportExportModelAdmin`, отображаемые поля, фильтр, поиск, автоматический slug |
| `Product` | `ImportExportModelAdmin`, `list_display`, `list_filter`, поиск, `date_hierarchy`, `list_display_links`, `raw_id_fields`, `readonly_fields`, действие экспорта PDF |
| `Order` | список, фильтры, поиск, readonly-поля и `OrderItemInline` |
| `Favorite` | список, поиск по email пользователя и названию набора |
| `Review` | отдельная админ-настройка и действия модерации (см. `product_reviews/admin.py`) |

У моделей есть человекочитаемые `__str__`, `verbose_name` и `verbose_name_plural`. Для цены со скидкой в `ProductAdmin` используется метод `final_price`, оформленный `@admin.display`.

## Сценарий демонстрации

1. Авторизоваться в `/admin/` под администратором.
2. Открыть «Наборы»: показать поиск, фильтр по серии и дату создания.
3. Открыть карточку набора: показать readonly-поля и выбор серии через `raw_id_fields`.
4. Выделить наборы и выполнить действие «Сформировать PDF со спецификациями выбранных наборов».
5. Открыть заказ и показать встроенные строки `OrderItemInline`.
6. Открыть историю `Product` или `Order`, затем экспорт категории или набора.

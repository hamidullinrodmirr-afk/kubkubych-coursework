# Отчёт по лабораторной работе 9
## Git в проекте «КубКубыч» — подтверждённая часть

### Цель работы
Описать организацию контроля версий и подтверждённые операции ведения проекта.

### Организация репозитория
Git хранит историю файлов проекта. Рабочая директория содержит текущие файлы, индекс — изменения, подготовленные к коммиту, а коммит фиксирует состояние выбранных файлов. Основная рабочая ветка — main.

### Подтверждённые операции
В ходе развития проекта использовались просмотр состояния, анализ diff, выборочное добавление файлов, создание коммитов и отправка в удалённый репозиторий. После отправки 6f42067 вывод status был:
~~~text
## main...origin/main
~~~
Он показывал отсутствие локальных изменений и синхронизацию ветки с её удалённой копией на момент проверки.

Основание реализации — текущий исходный код. Фрагменты сокращены и могут не быть самостоятельными исполняемыми блоками. Схемы не являются скриншотами. Код, настройки и данные проекта при подготовке отчёта не изменялись.

### Общая логика

Главная страница состоит из серверного HTML-каркаса и двух клиентских подборок. JavaScript получает JSON от API и создаёт карточки. Поиск переводит пользователя в каталог. За карточками стоят модели товаров, серий, отзывов, избранного и заказов.

## 3. Загрузка данных подборок

### Что это

Клиент получает массив товаров и заменяет содержимое контейнера карточками.

### Где находится

[templates/index.html](../templates/index.html) — Функция fill.

### Основной код

~~~javascript
async function fill(id, url, emptyText) {
    const box = document.getElementById(id);
    const data = await API.get(url) || [];
    box.innerHTML = data.length ? data.map(productCard).join('') : `<p class="empty-hint">${emptyText}</p>`;
}
~~~

### Как работает

static/js/api.js добавляет префикс /api к URL. fill вызывает общий productCard для каждого товара. Если API.get вернул null при неуспешном HTTP-ответе, он превращается в пустой массив и отображается как отсутствие данных. Сетевая ошибка fetch может отклонить Promise: локального try/catch у fill нет. Поэтому отдельное состояние ошибки загрузки нельзя считать реализованным.

### Визуализация

~~~text
Контейнер → API.get → массив → productCard → HTML
Пустой результат / null → emptyText
~~~

Состояние: Подборки загружаются; обработка ошибок не отделена полноценно от пустых данных.

## 6. Базовая выборка и агрегаты

### Что это

annotate добавляет вычисленные показатели к каждому товару.

### Где находится

[products/views.py](../products/views.py) — ProductViewSet.get_queryset.

### Основной код

~~~python
Product.objects.select_related('category').annotate(
    average_rating=Avg('reviews__rating', filter=Q(reviews__is_approved=True)),
    reviews_count=Count('reviews', filter=Q(reviews__is_approved=True), distinct=True),
    favorites_count=Count('favorited_by', distinct=True),
    sold_units=Coalesce(
        Sum('order_items__quantity', filter=Q(order_items__order__status=Order.Status.DELIVERED)),
        0,
    ),
)
~~~

### Как работает

Avg рассчитывает средний рейтинг одобренных отзывов, Count — число одобренных отзывов и отметок избранного, Sum — количество единиц в доставленных заказах. Coalesce заменяет отсутствие суммы нулём. select_related загружает серию; для неадминистратора выборка дополнительно ограничивается is_active=True. ProductListSerializer передаёт показатели в JSON. При нескольких коллекциях в JOIN сумма может размножаться: это аналитический риск, а не доказанная ошибка на текущих данных.

### Визуализация

~~~text
Product + Category
  ├─ Review → Avg, Count
  ├─ Favorite → Count
  └─ OrderItem → Order delivered → Sum
~~~

Состояние: Аннотации есть. Read-only сравнение sold_units с прямой суммой 16.09.2026 не выявило расхождений в текущей локальной БД; другие сочетания данных не проверены.

### Где находится

~~~python

    self.get_queryset().filter(discount_percent__gt=0)
    .order_by('-discount_percent')[:POPULAR_PRODUCTS_LIMIT]
~~~

### Визуализация

~~~text
Скидка >0 → процент ↓ → первые 8 → карточки
~~~

Состояние: Реализовано.

### Как работает

addToCart отправляет запрос корзины, а оформление заказа проходит на отдельной странице. Сервис берёт корзину текущего пользователя, проверяет пустоту, активность и остаток, считает final_price × quantity, проверяет диапазон 500–100000 ₽. Ошибка проверки → операция не завершается

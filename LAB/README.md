# Материалы для лабораторных работ

Папка содержит отдельные отчёты-заготовки по заданиям «Весна 2026». Перед загрузкой в СДО нужно заменить пункты `[СКРИНШОТ]` фактическими скриншотами из запущенного проекта и заполнить титульный лист по шаблону преподавателя. Неподтверждённые сведения не внесены.

| Лабораторная | Файл | Результат |
| --- | --- | --- |
| 1 | `lab-01-database.md` | Анализ и схема БД требуют добавления диаграммы |
| 2–7 | `lab-02-admin.md` … `lab-07-django-5.md` | Код и сценарии демонстрации |
| 8 | `lab-08-vim.md` | Выполняется вручную в Vim |
| 9 | `lab-09-git.md` | Выполняется по PDF задания и фиксируется скриншотами |
| 10–14 | `lab-10-frontend.md` … `lab-14-documentation.md` | Доработки и материалы для сдачи |

Общий запуск: `python manage.py migrate`, `python manage.py seed_store`, `python manage.py runserver`.

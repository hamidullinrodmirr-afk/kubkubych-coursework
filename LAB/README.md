# Материалы для лабораторных работ

Папка содержит рабочие Markdown-отчёты по заданиям «Весна 2026». Каждый отчёт фиксирует только проверенные по коду возможности, порядок демонстрации и необходимые доказательства. Перед загрузкой в СДО вставьте реальные скриншоты из запущенного проекта и титульный лист по шаблону преподавателя.

| Лабораторная | Файл | Результат |
| --- | --- | --- |
| 1 | `lab-01-database.md` | Предметная область, аналоги, роли и ER-схема |
| 2–7 | `lab-02-admin.md` … `lab-07-django-5.md` | Подтверждённые возможности и сценарии проверки |
| 8 | `lab-08-vim.md` | Пошаговый журнал ручного выполнения в Vim |
| 9 | `lab-09-git.md` | Каркас отчёта по операциям из PDF задания |
| 10–14 | `lab-10-frontend.md` … `lab-14-documentation.md` | Материалы по интерфейсу, страницам и документации |

## Подготовка доказательств

Общий запуск: `python manage.py migrate`, `python manage.py seed_store`, `python manage.py runserver`.

Для каждого отчёта сохраняйте скриншоты с адресной строкой или видимой навигацией, чтобы было понятно, что показан именно проект. Не добавляйте скриншоты чужих систем и не заявляйте выполнение пунктов, которых нет в коде.

# Лабораторная работа 8 Vim

## Цель

Зафиксировать выполнение операций редактирования в Vim на файле проекта.

## Порядок выполнения

Открыть копию несущественного файла проекта, например `LAB/vim-practice.txt`, командой `vim LAB/vim-practice.txt`. Выполнять только операции, указанные преподавателем, и после каждого раздела делать скриншот окна Vim.

| Раздел | Что зафиксировать |
| --- | --- |
| режимы | переход Normal → Insert → Normal, ввод и отмена действия |
| навигация | перемещение по строкам, словам и документу |
| поиск и замена | поиск текста и замена на безопасном тренировочном файле |
| файлы | открытие, сохранение, выход, справка |
| настройки | только параметры, предусмотренные заданием |

## Шаблон записи для каждого пункта

```text
Команда: TBD
Ожидаемый результат: TBD
Фактический результат: TBD
Скриншот: [вставить]
```

## Ограничение

Эта работа не подтверждается исходным кодом. Команды и скриншоты нужно получить вручную в собственной среде; не следует добавлять вымышленные результаты.

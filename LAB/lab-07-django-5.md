# Отчёт по лабораторной работе 7
## QuerySet, промежуточные связи и параметры формы

### Цель работы
Рассмотреть расширенные операции ORM и настройки формы на примерах каталога, аналитики и отзывов.

### Операции QuerySet
| Операция | Реализация и назначение |
| --- | --- |
| filter/exclude/order_by | Отбор и сортировка товаров |
| icontains | Поиск по названию, артикулу и описанию |
| Срез | Ограничение популярных подборок |
| values | Получение словарей для аналитики |
| values_list | Получение ID избранного и адресатов уведомлений |
| count | Подсчёт заказов и объектов |
| exists | Проверка покупки перед отзывом |
| update | Массовая модерация отзывов |
| delete | Очистка корзины и удаление избранного |

Пример проверки покупки:
~~~python
delivered = Order.objects.filter(
    user=user,
    status=Order.Status.DELIVERED,
    items__product=product
).exists()
~~~

Метод exists не загружает весь состав заказа для проверки существования. Переход items__product использует связь с позициями.

### Промежуточная модель
Favorite связывает User и Product, хранит дату добавления и ограничение уникальности пары. Она указана как through у ManyToManyField. Таким образом, связь хранит собственные данные, а не только идентификаторы объектов.

### Настройки формы
ProductForm содержит fields, widgets, labels, help_texts и error_messages. Textarea используется для описания и дополнительного примечания. clean_article читает cleaned_data. Представление вызывает is_valid, шаблон выводит подписи и ошибки полей. Внутренний класс Media подключает CSS формы. exclude в Meta формы не используется, поскольку применяется явный список fields.

### Пояснение F и Http404
F позволяет выразить вычисления на уровне базы: в analytics/services.py выручка позиции вычисляется как F('unit_price') * F('quantity'). get_object_or_404 возвращает объект либо HTTP 404 вместо необработанного отсутствия записи.

### Результат и вывод
Реализованы цепочки QuerySet, агрегирование, промежуточная M:N-модель и параметры ModelForm. Отдельный пример contains отсутствует; поисковый сценарий использует icontains. Это различие сохранено в отчёте.

# Лабораторная работа 3 Django 1

## Цель

Показать базовые средства Django на моделях, представлениях, URL, аутентификации и запросах проекта.

## Подтверждённые элементы

| Требование | Артефакт проекта |
| --- | --- |
| `__str__`, `Meta`, choices | `products/models.py`, `orders/models.py`, `cart/models.py` |
| `related_name` и двойное подчёркивание | связи моделей; запросы вида `order_items__quantity`, `reviews__rating` в `products/views.py` |
| пользовательский менеджер | `users/managers.py` |
| `timezone` | генерация номера заказа и даты статуса в `orders/models.py` |
| `get_absolute_url` и `reverse` | `Product.get_absolute_url()` |
| фильтрация и сортировка | `ProductFilter`, `ProductViewSet.get_queryset()` |
| агрегация и аннотация | `Avg`, `Count`, `Sum`, `Coalesce` в `products/views.py` |
| регистрация | `POST /api/auth/register/` и `users/views.py` |
| работа с изображениями | `ImageField` в `Category` и `Product`, зависимость Pillow |

## Что не следует заявлять без доработки

В текущем коде не найдены два собственных template filter и три собственных template tag. Если преподаватель требует эти пункты буквально, их нужно реализовать отдельным изменением; этот отчёт не подменяет отсутствие кода.

## Сценарий проверки

1. Открыть каталог и выполнить поиск или сортировку.
2. Открыть API `GET /api/products/popular/` и показать, что подборка упорядочивается по рассчитанным продажам и избранному.
3. Выполнить регистрацию через форму или API и убедиться, что создан пользователь.
4. Открыть `Product.get_absolute_url()` и запрос с аннотациями в исходном коде.
